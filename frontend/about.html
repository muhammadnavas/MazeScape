MAZESCAPE · GAME GUIDE

A maze, a ghost and one way out.

MazeScape is an independent browser-based maze escape game built around exploration, quick decisions and pathfinding. Navigate a maze, avoid the pursuing ghost, collect power-ups and reach the exit.

What you can experience

  • Procedurally generated maze layouts for changing runs.
  • Ghost movement supported by A* pathfinding.
  • Power-ups including Speed Surge, Ghost Freeze and Wall Breaker.
  • In-game score, lives and timer feedback.
  • Keyboard controls on desktop and touch controls on mobile.
  • An in-game explanation of the A* pathfinding algorithm.

Built for the browser

MazeScape uses HTML, CSS, JavaScript and the HTML5 Canvas API. Maze generation, movement, ghost behaviour and scoring run in the browser. There is no player account or online leaderboard, and game scores are not uploaded to a game server.

Why A*?

A* is a widely used pathfinding algorithm that combines the cost of the route already travelled with a heuristic estimate of the remaining distance. In MazeScape, it helps demonstrate how game characters can navigate a grid-based environment.
