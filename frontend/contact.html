MAZESCAPE · GAME GUIDE

Contact and feedback

Have an idea for MazeScape, noticed a bug or want to share feedback? Clear reports help improve the game and make it easier to play across devices.

Reach the project maintainer

Use the project's GitHub repository to report an issue or suggest an improvement. Include the browser and device you use, what you expected to happen, what actually happened and the steps to reproduce the problem.

Report an issue on GitHub

Helpful details to include

  • Whether the issue happens on desktop or mobile.
  • Your browser name and version, if known.
  • Which action or game state triggered the issue.
  • A screenshot or short screen recording, if it helps explain the problem.

Please do not include passwords, private account information or other sensitive data in a public issue.
