MAZESCAPE · GAME GUIDE

Think ahead. Find your way out.

MazeScape is a browser-based maze escape game. Each run asks you to navigate a generated maze, avoid a pursuing ghost, manage your lives and reach the exit. This guide explains practical ways to approach the maze and the pathfinding ideas behind the game.

1. Read the maze before you move

Look for corridors, dead ends and intersections. A route that looks short may force you into a corner, so keep an escape route in mind when the ghost is nearby. Move deliberately at junctions instead of repeatedly reversing direction.

2. Understand the ghost's pathfinding

MazeScape uses A* pathfinding to help its ghost find a route through the maze. A* is a search algorithm that ranks possible positions using the cost already travelled and an estimate of the remaining distance to the target.

The A* evaluation function

f(n) = g(n) + h(n)

  • g(n): the known cost from the starting position to node n.
  • h(n): a heuristic estimate of the remaining cost from node n to the goal.
  • f(n): the estimated total path cost through node n.

For a grid maze, a Manhattan-distance heuristic is often useful when movement is limited to horizontal and vertical neighbours. A* repeatedly explores promising nodes until it reaches the target or determines that no route is available.

3. Use power-ups with a plan

  • Speed Surge: use the temporary speed boost to cross an exposed corridor or create distance from the ghost.
  • Ghost Freeze: activate it when the ghost is close or blocking a route you need.
  • Wall Breaker: use the temporary ability to open a route when the normal maze layout is working against you.

Power-ups are most useful when they solve a specific problem. Save them for a dangerous junction or a difficult escape rather than activating them without a plan.

4. Make each run count

Watch your remaining lives and score while exploring. Avoid unnecessary backtracking, learn the maze layout as you move and prioritise reaching the exit safely. If a run ends, use what you learned about the corridors and ghost movement in your next attempt.

Put these ideas into practice in a new MazeScape run. The game runs directly in your browser, with no account or download required.
